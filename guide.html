How to use RodentStudio

User guide

A concise workflow from imported video to reviewed research outputs.

RodentStudio is a macOS workspace for organising rodent behavioral video experiments, reviewing tracking output, and exporting structured results. It runs on a Mac; it is not an iPhone app.

Getting started

  1. Create a task. Choose a supported behavioral workflow, then add notes describing the experimental setup.
  2. Add a video. Select a local MP4 or MOV file and confirm animal ID, date and session number. Add group and other optional metadata if useful.
  3. Calibrate. Set the appropriate arena, reference scale, regions or analysis window for the selected assay.
  4. Run analysis. Start the configured tracking workflow and allow video processing to finish. Available models and outputs depend on the assay.
  5. Review. Inspect the trajectory or keypoint overlays, mark questionable frames, and check the generated measurements.
  6. Export. Export the supported results and review artifacts to a user-selected location for independent analysis.

Analysis families

RodentPoseMousePose6-based single-animal pose tracking for supported assays.
RodentLimbCylinderMousePoseV2-based tracking for supported limb workflows.
RodentFlowClassic centroid tracking and selected behavioral calculations, without a neural network in that tracking path.
Project hierarchyTasks, groups, animals and individual sessions, with notes and exports.

Working with research data

Record the species, camera viewpoint, calibration, model, session grouping, analysis interval and any exclusions. Use the exported per-session data for reproducible analysis. Group-level summaries are aids, not a substitute for a prespecified statistical analysis plan.

Scientific validation: This software is a research aid. Verify pose tracking, calibration, event labeling and calculated metrics against manual review or validated reference measurements before using results in publications or consequential decisions. Supported output varies by workflow.

Compatibility and models

The project targets macOS 14 or later. The app uses bundled Core ML resources for supported pose workflows; users of an App Store build should not need to install Python or separately download model weights. Compatibility and bundling must be checked in the final signed release.

The separate Core ML models repository is a developer resource, not a required step for App Store users. A third experimental JABS model in that repository is not represented here as integrated into the macOS app.
