# RodentPose 1.0（Xcode 工程）

在 iPhone / iPad 上逐帧识别小鼠 6 个关键点（鼻尖、左耳、右耳、颈部、身体中心、尾根），并按经典行为范式自动计算指标。

**核心识别模型沿用原 MousePose 版本**：模型文件仍叫 `MousePose6_960_int8`，画面先摆正、可选先转灰度，再交给 YOLO pose，每帧取置信度最高的检测。RodentPose 在此基础上提供了范式分析、标定、结果看板、回看和数据管理。

---

## 3 步跑起来

1. **打开工程**：双击 `RodentPose.xcodeproj`（需要 **Xcode 26 或更新（上架需要 iOS 26 SDK）**）。第一次打开会自动下载依赖包 UltralyticsYOLO，等左侧 Package Dependencies 加载完。模型 `MousePose6_960_int8.mlpackage` 已经在 `RodentPose/` 文件夹里。
2. **签名**：左侧点蓝色 RodentPose 工程 → TARGETS: RodentPose → **Signing & Capabilities** → Team 选你的 Apple ID。如果提示 Bundle Identifier 已被占用，把 `com.ziqingshi.RodentStudio` 改成别的名字。
3. **装到手机**：顶部选你的 iPhone → ⌘R。系统要求 **iOS 17 或更新**（旧版 MousePose 1.0 是 iOS 16）。

> **品牌更新**：App 名称、Xcode target、文件共享显示名以及导出品牌标识已更改；`MousePose6_960_int8.mlpackage` 是模型资源名，为避免加载失败保持不变。新 Bundle Identifier 是 `com.ziqingshi.RodentStudio`。如果手机装过旧 Bundle ID 的版本，新版本会视为另一个 App，旧沙盒数据不会自动转移；请先通过旧 App 的「文件」或导出功能备份。

> 工程使用“文件夹同步”（Xcode 16 的 synchronized group）：`RodentPose/` 里的所有 `.swift`、`Assets.xcassets` 和模型都会自动加入 target，不需要手动添加文件。

## 使用流程

**首页 → 新建分析 → 选范式 → 导入视频（相册或“文件”）**，之后在一个全屏工作区里按 4 步完成：

| 步骤 | 做什么 |
|---|---|
| ① 信息 | 编号、组别、性别、阶段 / 条件（预设或用 ＋ 添加自己的标签，可不选）、天 / 试次、备注；识别设置（抽帧、灰度、双鼠、识别范围） |
| ② 标定 | 拖动手柄对齐场地（矩形四角 / 圆心+边缘 / 迷宫中心+臂末端），拖动物体、杯子、巢穴、目标洞等标记；填写尺寸（cm）和范式参数 |
| ③ 识别 | 运行模型，实时显示骨架预览、进度、速度、剩余时间；可暂停，切到后台会自动暂停并保存，之后可继续 |
| ④ 结果 | 主指标、全部指标、轨迹与区域图、热图、时间轴、柱状 / 曲线 / 极坐标图、识别质量、可直接写进论文的方法说明 |

- **改区域或阈值不需要重新识别**：识别结束后回到“标定”，拖动手柄或修改参数，结果在顶部的“实时预览”中即时更新。
- **三箱中箱分隔线**：紫色 L/R 手柄分别拖动左右分隔线，可以移动中箱和改变中箱宽度，不再强制左右箱等宽；黄色 1–4 校准整个外场，青色 L/R 校准杯子。拖动时先本地预览，松手后统一提交并重算指标，因此不会每次手指移动都触发整次分析。
- **回看**：视频 + 骨架 + 区域 + 2 秒轨迹（去除跳点并平滑，仅用于显示，不影响指标），逐帧前进 / 后退，0.25×–2× 播放；下方时间轴显示检测到的行为（嗅探、僵直、探头……），点击或拖动即可跳转。
- **说明按需查看**：分析流程各页只保留操作和结果；拍摄建议、参数含义、指标定义、图注、识别质量详情和方法说明都在卡片右上角的 ⓘ 里，范式背景知识在“范式库”。
- **批量处理**：同一范式、同一分辨率的下一个视频会自动沿用上一个的标定、参数和组别。结果页菜单里有“下一只（同范式）”。
- **数据页**：按日期分组，可搜索、按范式筛选；左滑删除整次分析，或只删除视频副本（保留数据）；右上角导出**汇总表 CSV**（每只动物一行）。

## 范式与“为什么需要姿态”

| 类别 | 范式 | 依赖关键点的指标 | 主要依据 |
|---|---|---|---|
| 社交 | 三箱社交 | 鼻尖距杯外缘 ≤ 2 cm + 头朝向 ±45° 的嗅探时间、社交指数 / 新颖性指数 | Moy et al. 2004; Yang et al. 2011 |
| 社交 | 社交回避测试（CSDS） | 互动区 / 角落区时间、鼻尖嗅探网罩；同编号两阶段自动配对算 SI ratio | Golden et al. 2011 |
| 社交 | 双鼠社交互动 | 鼻–鼻、鼻–尾根（肛殖区）、鼻–身体接触，跟随，间距 | MARS (Segalin et al. 2021) |
| 导航 · 神经记录 | 头朝向 | 两耳中点→鼻尖的 HD、6° 占据极坐标图、覆盖度、平均向量长度、AHV、头–身夹角；可用提示卡作 0° | Taube et al. 1990; Peyrache et al. 2015 |
| 导航 · 神经记录 | 空间探索 · 位置细胞 | 占据图（2.5 cm）、覆盖度及其增长曲线、运动时间（> 2 cm/s）、速度分布 | O'Keefe 1971; Hafting et al. 2005 |
| 焦虑 | 高架十字迷宫 | 开放臂时间 / 进入 %（身体中心+尾根进入）、**探头**（受保护 / 非保护）、**伸展评估姿势 SAP** | Walf & Frye 2007; MATSAP (Holly et al. 2016) |
| 焦虑 | 明暗箱 | 明箱时间、穿梭、潜伏期、**探头**（鼻在明箱、身体在暗箱） | Bourin & Hascoët 2003; Takao & Miyakawa 2006 |
| 焦虑 | 旷场 | 中央区、路程、静止、按身体轴向的转圈 | Prut & Belzung 2003 |
| 记忆 | 新物体识别 | 鼻尖 2 cm + 朝向的探索（排除攀爬）、DI、RI、达到 20 s 的时间、累计 DI 曲线 | Leger et al. 2013; BehaviorDEPOT |
| 记忆 | Barnes 迷宫 | 以**鼻尖探洞**计首次 / 总错误数、首次潜伏期、路径长度、起始朝向误差、目标象限 | Barnes 1979; Pitts 2018 |
| 记忆 | Y 迷宫自发交替 | 交替率（身体中心+尾根进入）、**探头未进入** | Hughes 2004; Kraeuter et al. 2019 |
| 记忆 | T 迷宫 · VTE | 每次选择的 IdPhi（头朝向 / 轨迹）、会话内 zIdPhi、VTE 比例、交替 | Redish 2016 |
| 恐惧 | 恐惧条件化 | 关键点僵直（0.5 s 窗口 < 1 cm/s，≥ 1 s）、基线 / 每个 CS / CS 间隔、每分钟曲线 | Anagnostaras et al. 2010; BehaviorDEPOT |
| 恐惧 | Looming 逃跑 | 反应潜伏期（> max(4×基线, 15 cm/s)）、10 s 内回巢、峰速、僵直、刺激时头–巢夹角 | Yilmaz & Meister 2013; Vale et al. 2017 |
| 运动 | 旋转行为（单侧损伤模型） | 身体轴向整圈数（顺 / 逆、同侧 / 对侧）、净旋转 / min、分段曲线 | Pycock 1980 |
| 通用 | 仅导出姿态 | 逐帧关键点 + 平滑坐标、速度、头朝向、身体轴向等，供 Keypoint-MoSeq / B-SOiD / SimBA 使用 | — |

每个范式的定义、拍摄建议和带 DOI 链接的参考文献都在 App 的“范式库”中；所有阈值都可以在“标定”页调整。

### 统一的数据处理
1. 置信度 < 0.5（可调）的关键点视为缺失；
2. 标定后转换为厘米（矩形用四点单应性校正透视，圆形 / 迷宫用比例尺）；
3. 去除不合理的跳变（> 150 cm/s），≤ 0.5 s 的缺口线性插值；
4. 0.15 s 滑动平均平滑；
5. 派生：身体中心速度、头朝向（两耳中点 → 鼻尖，缺失时颈部 → 鼻尖）、角速度、身体轴向（尾根 → 颈部）、头–身夹角、身体长度（鼻尖 → 尾根）、僵直用的运动指数。
6. “分析时间段”（起点 + 时长）只影响统计，不需要重新识别。

## 导出

结果页 → 导出（勾选需要的文件，系统分享面板发送到“文件”、AirDrop、邮件等）：

| 文件 | 内容 |
|---|---|
| `*_metrics.csv` | 本次全部指标（metric_key, metric, value, unit） |
| `*_frames.csv` | 逐帧：frame, time_s, in_window，6 个关键点的平滑坐标（cm），速度、head_direction_deg、ahv_deg_s、body_angle_deg、head_body_angle_deg、body_length、motion，以及范式相关的标记列（如 in_open_arm、head_dip、freezing、sniff_left……） |
| `*_keypoints.csv` | 模型原始输出：`frame,time_s,det_conf,<kp>_x,<kp>_y,<kp>_conf`（像素坐标，摆正后的画面，左上角为原点；**与原 MousePose 1.0 版 CSV 格式兼容**；双鼠时列名加 `m1_` / `m2_` 前缀） |
| `*_report.json` | 指标、注意事项、方法说明、识别质量、完整的会话设置（标定、参数） |
| 汇总表（数据页） | 每次分析一行：subject, group, sex, phase, day, trial, paradigm, date, video, notes, detection_rate + 所有指标。列名可被 **RodentFlow 的“导入表格”** 识别，可直接用于组间统计 |

CSV 为 UTF-8 带 BOM，Excel 直接打开中文不乱码。

**与神经数据对齐**：逐帧 CSV 的 `time_s` 是视频的显示时间戳（与视频播放器一致）。记录系统与摄像头之间的同步偏移（如 TTL / LED）需要你自己加上。

## 数据存储

全部只在本机：“文件”App › 我的 iPhone › RodentPose › `Sessions/<编号>/`
- `session.json`：设置、标定、参数和指标缓存
- `pose.mpt`：逐帧关键点（二进制，App 内可导出为 CSV）
- `video.*`：视频副本（可在“数据”页单独删除以节省空间）
- `thumb.jpg`：标定用的缩略图

## 已知限制

- **双鼠模式**：按位置连续性分配身份，两鼠紧贴或重叠后 A / B 可能交换；总社交时间不受影响，区分个体的指标请回看确认。模型如果主要用单鼠视频训练，两鼠贴靠时检出率可能下降。
- **iOS 不允许在后台使用 GPU**：识别时请保持 App 在前台（屏幕不会自动锁定）；切到后台会自动暂停并保存，回来后点“继续识别”。
- 所有基于区域的指标都假设摄像头**大致正上方俯拍**；矩形场地可以校正透视，圆形和迷宫按比例尺换算。
- 默认阈值来自文献或常见做法，不同品系、体型和拍摄条件下请先用“回看”抽查再定。

## 代码结构（`RodentPose/`）

| 文件 | 内容 |
|---|---|
| `PoseInference.swift` | 模型加载、逐帧识别（1.0 的识别流程 + 时间范围、断点续跑、双鼠、实时预览）；`DirectPoseModel` 直接走 Vision，跳过 UltralyticsYOLO 每帧生成标注图的开销，并在每次运行的前几帧与原路径逐点比对 |
| `PoseTrack.swift` | 逐帧关键点存储、二进制读写、原始 CSV、双鼠身份分配 |
| `Paradigms.swift` | 16 个范式的说明、指标定义、参数、标记、参考文献 |
| `SessionModels.swift` | 会话、标定、识别设置、分析参数（JSON，容错解码） |
| `Geometry.swift` · `Zones.swift` | 向量 / 角度、单应性、图像→厘米映射、各范式的区域 |
| `Kinematics.swift` | 预处理与派生运动学、行为片段（bout）工具 |
| `TrailSmoothing.swift` | 回看拖尾与标定页轨迹的显示用平滑（去尖峰、断线、插值、平滑；不参与分析） |
| `Analysis*.swift` · `Analyzers*.swift` | 通用分析上下文和各范式分析器，输出指标 + 图表数据 |
| `Export.swift` | CSV / JSON / 文字摘要 |
| `AppModel.swift` · `SessionStore.swift` | 应用状态、单次分析的工作流、磁盘存储 |
| 其余 `*View.swift` | 界面：首页、范式库、数据、工作区四步、结果图表、回看、设置 |

## 应用内语言切换 / 英文科研数据

进入 **设置（右上角齿轮）→ 语言**，可直接选择 **跟随系统 / 中文 / English**，不需要修改 iPhone 的系统语言。
无论界面使用什么语言，自动生成的科学数据（CSV 列名、指标、JSON 描述、Methods、warnings 和汇总结果）都使用**英文**。受试动物编号、组名、备注、视频文件名等用户自行填写的内容保留原文；如需整份数据全英文，请用英文填写这些内容。

具体规则见 `LANGUAGE_AND_DATA_POLICY.md`。
