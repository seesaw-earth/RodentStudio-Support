## 左侧：任务 → 分组 → 小鼠 → 实验

```
旷场（任务）
├─ WT（分组，有分组时才出现）
│  ├─ M01（小鼠）
│  │  ├─ 2026-10-17 · #1（一次实验 = 一段视频）
│  │  └─ 2026-10-24 · #2
│  └─ M02
└─ KO
```

- 工具栏 **新建任务**（⇧⌘N）：选择行为学任务（决定标定方式、分析方法和模型）。
- 工具栏 **+ 添加视频**（⌘O，也可把视频拖到侧边栏）：每段视频必须填写 **小鼠编号、实验日期、实验次数**；分组、性别、阶段按需填写。日期和编号会从文件名预填，请核对。在分组或小鼠上添加时会自动带上该分组 / 小鼠。
- 点 **任务**：全部实验表格、**组间比较**、**任务级导出**。
- 点 **分组**：该组的小鼠、各阶段描述统计、**组级导出**、重命名分组。
- 点 **小鼠**：它的各次实验、某个指标随实验次数的变化、修改编号 / 分组 / 性别。
- 点 **某次实验**：四步流程 ——
  1. **实验信息**：小鼠、分组、性别、日期、实验次数、阶段 / 天 / 试次、备注、是否排除出组间汇总（需写原因）。
  2. **校准**：该任务原版 App 的标定与参数（包括分析时间段、物体 / 目标标记），是结果的唯一来源。
  3. **分析**：只做追踪；所有视频进同一队列，可暂停、继续。
  4. **复核与导出**：
     - **结果**：原版 App 的结果页，自动计算；可导出 CSV / JSON / PNG（英文）。
     - **逐帧复核与导出**：带 **播放键**（⌥P，速度 逐帧 / 0.25× / 0.5× / 1× / 2×）。设定复核范围（默认第 0–99 帧），播放或逐帧查看，标记错误帧（⌥F），记录“追踪无误 / 有问题”。RodentPose / RodentLimb 还可导出原始关键点、质控图、标注 MP4；RodentFlow 可导出质心采样点。
     右上角“下一次实验 →”跳到下一次待复核的实验。

原来的“快速复核”页已去掉，功能合并进“逐帧复核与导出”。

## 数据怎么算（详见 DATA_PROCESSING_CN.md）

1. 每次实验：原版分析器 + 该实验自己的标定、时间段、阶段和参数（与“结果”页完全相同）。
2. 每只小鼠：同一阶段内，纳入的多次实验先取平均 → **n = 小鼠数**。不同阶段不合并。
3. 每个分组：小鼠值的描述统计；组间比较给出初步检验（RodentFlow 1.3 的方法），未对多个指标做校正。
4. 被排除的实验保留自己的结果，只是不进入小鼠均值和组统计；导出时列出原因。

## 其他区域

- **数据（⌘2）**：每次实验一行（含日期、实验次数、标定、分析、追踪复核）；双击回到“分析”。
- **高级（⌘3）**：模型状态、手动追踪、长视频工具、手动结果复核、任务目录、旧项目查看器。

## 各模块现状（如实）

| 模块 | 标定 | 追踪 | 结果与图 |
|---|---|---|---|
| RodentPose（16 个范式） | 按原版移植 | MousePose6（Core ML，逐帧） | 原版 RodentPose 1.0 分析器与图（桌面移植）；双鼠范式只能单鼠追踪、不出结果 |

所有结果和统计都**尚未与 iOS 原版做数值一致性验证**；用于发表前请用同一视频在 iOS 和桌面版对照，并与人工评分比较。
