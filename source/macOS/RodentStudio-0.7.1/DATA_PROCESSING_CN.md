# RodentStudio 0.6.0 数据组织与处理逻辑

本文说明 RodentStudio 如何组织数据、一个数字从视频到组间比较经过哪些步骤，以及每一步的规则。界面、导出和代码都遵循同一套规则。

## 1. 数据层级

```
项目 Project
└─ 任务 Task（一个行为学测试，例如 旷场 / 新物体识别 / 圆筒）
   └─ 分组 Group（可选，例如 WT / KO / Vehicle；属于小鼠）
      └─ 小鼠 Animal（小鼠编号，任务内唯一）
         └─ 实验 Session（= 一段视频：实验日期 + 实验次数 #1、#2 …）
```

- **一段视频 = 一只小鼠的一次实验。** 添加视频时必须填写：小鼠编号、实验日期（yyyy-MM-dd）、实验次数（该小鼠在此任务中的第几次，1、2、3 …）。缺任何一项都不能导入。
- 导入窗口会尽量预填：日期取自文件名（2026-10-17 / 2026_10_17 / 20261017 等），文件名里没有就取文件创建日期并提示核对；小鼠编号取文件名去掉日期后的部分；实验次数自动取该小鼠下一个未用的号码。
- **同一任务内，同一只小鼠的实验次数不能重复**（导入时、在“实验信息”中修改时都会检查，冲突时标红且不保存）。
- **分组和性别属于小鼠**：同一任务中一只小鼠的所有实验分组相同。给已有小鼠添加新实验时，分组自动沿用；在小鼠页或实验信息中修改分组，会应用到它的全部实验。
- 阶段（训练 / 测试等）、天、试次仍按原版 App 的要求出现，属于每次实验。
- 早期版本导入、缺少日期或实验次数的视频在侧边栏显示橙色标记，补全“实验信息”前不能分析。

侧边栏就是这个层级：任务 → 分组（有分组时才出现）→ 小鼠 → 实验（日期 · #次数）。点任务、分组、小鼠打开对应的汇总页；点某次实验进入“实验信息 → 校准 → 分析 → 复核与导出”。

## 2. 单次实验的数值（Session level）

每次实验的指标只由**该任务原版 App 的分析器**计算（RodentPose 1.0、RodentLimb 1.1.2、RodentFlow 1.3 的桌面移植），输入为：

- 该实验已保存的追踪结果（不会重新追踪）；
- 该实验在“校准”中保存的标定、分析时间段和参数；
- 该实验的阶段（未填写 = 任务默认阶段）。

“结果”页、单次实验导出、任务 / 分组汇总都走同一条计算路径（`SessionResultsEngine`），所以同一次实验在各处的数字完全相同。

**缓存**：每次实验的指标摘要保存在该次追踪结果的文件夹中（App 自己的容器内，`rodentstudio_session_metrics.json`），并带有一个密钥（SHA-256），由以下内容计算：任务、追踪结果文件夹、模型、帧数、完成时间、阶段、该模块的全部标定与参数、分析器版本。任何一项变化（重新分析、改标定或参数、改阶段、升级分析器）都会使旧摘要失效并重新计算。原始视频永远不会被修改。

任务页、分组页、小鼠页打开时，会在后台按顺序计算缺少或过期的摘要（与“结果”页相同的分析），进度显示在页面顶部，可停止。

## 3. 小鼠水平（Animal level）

- **实验单位是小鼠**：n = 小鼠数，不是实验数，更不是帧数。
- 在同一个阶段内，一只小鼠的多次（纳入的）实验先取平均，得到这只小鼠的一个值。
- **不同阶段永远不合并**（例如 水迷宫 学习期和探针试验、NOR 训练和测试）。组间比较默认选该任务的分析阶段；选择“全部阶段合并”时会显示警告。
- 也可以只分析某一次实验（“仅第 n 次”），或用“按实验次数”设计看跨实验次数的变化。

## 4. 排除

- 在实验信息、实验表格右键或侧边栏右键中可把某次实验“排除出组间汇总”，需要写原因。
- 被排除的实验**保留自己的结果和导出**，但不进入小鼠均值、组统计、组间比较和汇总文件中的 animals.csv / group_summary.csv；sessions.csv 和 metrics_*.csv 中仍列出并标明 excluded = yes 和原因。
- 组间比较可勾选“包含已排除的实验”做对照查看。
- 有质控警告（例如检出率低于 80%、探索时间不足）或追踪复核结论为“追踪有问题”的实验**不会被自动排除**；组间比较会列出它们，由你按预先设定的标准决定是否排除。

## 5. 组间比较（初步统计）

方法移植自 RodentFlow 1.3 的组间分析，并推广到三个模块的全部任务：

| 设计 | 每只小鼠的值 | 两组 | ≥ 3 组 |
|---|---|---|---|
| 组间比较 | 该阶段（及所选实验次数）纳入实验的均值 | Welch t 检验（附均值差 95% CI）/ Mann–Whitney U | 单因素 ANOVA + Tukey–Kramer，或各组与第一组 Welch t + Holm；非参数：Kruskal–Wallis + Dunn（Holm） |
| 按实验次数（新增） | 每个实验次数一个值 | 两因素混合方差分析（组 × 实验次数，Greenhouse–Geisser 校正）；各次的组间比较 Welch t / Mann–Whitney，全部比较一起 Holm 校正 | 同左 |
| 按天 | 同一天的试次先平均 | 同上 | 同上 |
| 时间进程 | 每次实验内的序列（时间段、CS 呈现） | 同上 | 同上 |
| 配对指标 | 同一小鼠的两个指标（如 新物体 vs 熟悉物体、开放臂 vs 闭合臂） | 组内：配对 t / Wilcoxon；组间：混合方差分析交互作用 / 差值的 Mann–Whitney 或 Kruskal–Wallis | 同左 |
| 阶段间变化 | 每只小鼠 阶段 B − 阶段 A | 同“组间比较” | 同“组间比较” |

- “与第一组比较”时，第一组视为对照（默认把名称像对照的组，如 WT / Control / Vehicle / Saline / Sham，排在最前；可在比较页调整顺序、颜色和是否纳入，按任务保存）。
- 与参考值比较（可选）：只对原版定义了“无偏好值”的指标提供，例如 DI = 0、识别指数 = 50%、目标象限 = 25%。
- **这些是初步统计**：没有对多个指标、多种设计或多次查看数据做校正；用于报告前请用预先设定的分析确认。每组少于 2 只或数值完全相同的情况不给检验结果，并说明原因。
- 同一小鼠编号出现在两个分组中时会提示检查分组。

## 6. 导出（全部英文，保留原始编号）

**任务级导出**（任务页 → 导出）和**组级导出**（分组页底部）生成一个新文件夹：

| 文件 | 内容 |
|---|---|
| `sessions.csv` | 每次实验一行：任务、小鼠、分组、性别、日期、实验次数、阶段、天、试次、是否排除及原因、结果状态、追踪复核结论与标记数、质控警告、分析时间段、主要指标及其值、视频文件、追踪结果文件夹、备注 |
| `metrics_long.csv` | 每次实验 × 每个指标一行（指标键、英文名、单位、数值、是否主要指标） |
| `metrics_wide.csv` | 每次实验一行，每个指标一列（列名：英文名 (单位) [键]） |
| `animals.csv` | 每只小鼠 × 每个阶段一行：纳入实验的均值、纳入实验数、实验次数和日期 |
| `group_summary.csv` | 每个阶段 × 分组 × 指标：n（小鼠数）、均值、SD、SEM、中位数、四分位数、最小值、最大值 |
| `README_methods.txt` | 上述处理规则、计数、被排除的实验及原因、警告 |

**组间比较导出**（组间比较页）：`comparison_figure.png`、`comparison_summary.txt`（与 RodentFlow 相同格式的方法与结果摘要）、`comparison_result.json`（完整结果）、`comparison_animal_values.csv`（每只小鼠进入检验的数值）。

**单次实验导出**不变：“结果”页导出原版 App 的指标、图和方法（元数据中新增 session_date、session_number、excluded、exclusion_reason）；“逐帧复核与导出”导出原始关键点 / 质控 / 标注视频（RodentFlow 为质心采样点 CSV 和复核记录）。

## 7. 追踪复核

“快速复核”页已合并进“逐帧复核与导出”：

- 播放键（⌥P）：从当前帧播放到复核范围末尾（当前帧不在范围内时播放到视频结尾）；速度可选 逐帧 / 0.25× / 0.5× / 1× / 2×。逐帧模式不跳帧；其他速度按视频时钟播放，解码跟不上时跳过的帧不计为“已查看”。
- 不必看完整个视频：设定复核范围（默认第 0–99 帧，可选开头 / 中间 / 结尾 / 随机），标记追踪错误的帧（⌥F），记录“追踪无误 / 追踪有问题”和备注。
- 只有与追踪时间戳对上的画面才画标点；对不上时隐藏标点并说明原因。
- 复核结论保存在该次实验上，属于当前这次追踪结果；重新分析后需要重新复核。

## 8. 尚未验证的部分（如实）

- 本版本在没有 macOS SDK 的环境中编写，只做了语法和工程文件检查，**没有编译和运行过**。
- 桌面移植的分析器尚未与 iOS 原版逐一做数值一致性验证；统计引擎是 RodentFlow 1.3 StatsEngine 的逐行移植，同样尚未在桌面上与 iOS 结果对照。
- RodentPose 的配对指标（新物体 / 刺激侧 / 开放臂 / CS 僵直）与参考值，是把 RodentFlow 的同类比较套用到 RodentPose 的同名指标上，指标本身未改动。
