# 0.5.1（基于 0.5.0）

## 产品逻辑（文件切换 / 任务切换 / 一致性）
逐条见 `LOGIC_AUDIT_0.5.1_CN.md`。要点：
- 复核页的结果按“视频 + 结果文件夹”识别：切换视频、重新分析（新文件夹）后不会再显示上一只动物或上一次分析的结果；读取失败会提示并可重试，不再一直显示“正在读取”。
- 批量分析结束时不再把某只动物的结果强行载入共享会话；复核页自己按需载入。
- 所有分析（RodentPose、RodentLimb、RodentFlow）走同一个队列：一次一个视频，可“暂停”“全部暂停”“移出队列”，等待中的视频保持原状态（不会被标成“已暂停”）。侧栏显示排队位置。
- RodentFlow 的追踪不再挂在某个界面上：离开页面不会丢失进度，也不会重复启动；“分析”只追踪，“复核”只看结果。
- 结果只用“校准”中保存的分析时间段、区域与参数（RodentPose 的分析起点/时长、RodentFlow 的分析窗口、RodentLimb 悬尾窗口），与原版 App 相同；复核页的帧范围只用于质控图、原始导出和 MP4。
- 阶段：未填写时一律使用该任务的默认阶段（标定、分析、导出一致）。
- RodentFlow：NOR / 水迷宫 / Barnes 使用“校准”中放置的物体 A/B、平台/目标标记（按追踪器的同一映射换算为 cm），不再使用默认位置；检测标志与原版一致（`!interpolated`）；记录追踪时的标定，标定改动后给出提示；暂停后场地标定被改动则拒绝续跑。
- RodentPose 分析文字使用原版 RodentPose 的翻译表（EnglishTranslations.json / L10nPatterns.json）：界面跟随语言，导出始终英文（0.5.0 中导出的指标名是中文）。

## 原版 App 的图
- RodentPose：主指标卡（含标尺）、全部指标、场地轨迹/热图（区域、起终点、比例尺、图例）、行为时间轴、柱状图、折线图（试次叠加+均值、读数）、极坐标图、表格、识别质量、方法说明。每张图可复制图像、保存 PNG、复制数据（CSV，英文）。
- RodentLimb：Summary 与 Measures 两页的全部卡片（主指标、提示、悬尾运动曲线与每分钟不动、圆筒前爪使用/触壁时间分布/触壁列表、步态足落/模式/各爪参数/肢间相位/足印）。
- RodentFlow：结果网格（原版指标名、单位、小数位，主指标在前）、场地 轨迹/热图（只画分析窗口，含区域和标记）、恐惧条件化僵直时间线、时间段序列图、序列与标签、方法与参数。
- “导出结果与图表…”：每只动物新建文件夹，写入指标 CSV、JSON、方法文本、各图 PNG（420 pt × 3 倍，与 iOS 相同）和图数据 CSV。文件名见 `FIGURES_PARITY_CN.md`。

## 快速复核（不必逐帧）
- 复核页新增“快速复核”：选一个范围（默认第 0–99 帧，可选 50/100/200/500/1000，开头/中间/结尾/随机），逐帧或播放查看叠加在视频上的已保存追踪，标记追踪错误的帧，记录“追踪无误 / 有问题”与备注。
- 复核结果保存在该视频的记录里，属于当前这次分析；切换视频、任务、页面或语言都不会丢失；侧栏和“数据”表格显示复核状态；导出写入复核信息。
- “逐帧复核与导出”中的事件判定和备注也保存到视频。
