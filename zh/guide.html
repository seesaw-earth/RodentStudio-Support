开始使用 RodentStudio

使用指南

从导入视频到科研结果复核与导出的基本步骤。

RodentStudio 是原生 macOS 小鼠行为视频分析软件，用于组织实验、视频追踪、逐帧复核与科研结果导出。它是 Mac 桌面软件，不是 iPhone App。

基本使用流程

  1. 新建任务：选择受支持的行为学任务，填写实验设置和备注。
  2. 导入视频：选择本地 MP4 或 MOV 视频，确认动物编号、日期、实验次数；按需添加分组等信息。
  3. 完成标定：按任务设置场地边界、尺寸参照、兴趣区域或分析时间段。
  4. 运行分析：选择相应流程进行跟踪；不同任务支持的模型和输出并不相同。
  5. 人工复核：查看轨迹或关键点叠加、标记可疑帧并核对结果。
  6. 导出数据：导出该流程支持的结构化结果、图表和复核文件。

分析模块

RodentPose使用 MousePose6 的受支持单鼠姿态跟踪任务。
RodentLimb使用 CylinderMousePoseV2 的受支持肢体运动任务。
RodentFlow使用传统质心追踪的部分行为指标，当前该跟踪路线不依赖神经网络。
实验数据层级任务、分组、动物、单次实验，支持备注和导出。

科研数据管理

建议完整记录物种、视角、标定、模型、分组、分析时间段和排除依据。统计结果应结合正确的实验单位与独立统计方案使用。

科研验证：本软件是辅助分析工具。用于论文或重要决策前，应与人工标注或经过验证的参考数据核对姿态追踪、事件分类、标定及统计指标；不同任务支持程度不同。

系统与模型

项目配置的最低部署系统为 macOS 14。计划通过 Mac App Store 发布的安装包应内置受支持的 Core ML 模型，普通用户不应需要安装 Python 或下载模型权重；正式版本仍需完成打包和设备测试。

独立的Core ML 模型仓库用于开发者分发模型。仓库中的第三个 JABS 模型目前不能据此认定已接入 RodentStudio Mac App。
