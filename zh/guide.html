1. 概览：我该用哪个版本？

RodentFlow 在你自己的设备上分析你自己拍摄（或有权使用）的实验啮齿类视频。无需注册账号，也不会上传：视频、追踪数据和结果都留在你的 Mac、iPhone 或 iPad 上（详见隐私政策）。它有两个版本，科研计算逻辑相同，但面向的工作场景不同。

RodentFlow（Mac 版）RodentFlow Mobile（iPhone / iPad）
适合完整课题：多只动物、多个分组、多次实验、统计和批量导出单段视频快速分析、在实验台旁检查录像、教学演示
系统要求macOS 14 Sonoma 或更新（推荐 Apple 芯片）iOS / iPadOS 17 或更新
分析模块RodentPose（16 个范式）、RodentLimb（3 个）、RodentFlow（10 个）、多格 TSTRodentPose（16 个范式）
数据组织项目 → 任务 → 分组 → 小鼠 → 实验每段视频一次分析，含编号、组别、阶段、天、试次
组间统计内置“组间比较”（t 检验、方差分析、混合方差分析、非参数检验）导出汇总表后在其他软件中分析
导出实验 / 分组 / 任务级表格、图表、方法说明、DeepLabCut 格式逐帧数据、TST 专用文件指标汇总 CSV、逐帧分析 CSV、原始关键点 CSV、完整报告 JSON、汇总表

2. 拍摄之前

大多数“软件算错了”其实是拍摄问题。花十分钟把相机摆好，能省下好几个小时的重新分析。

相机与光照检查清单

  1. 固定相机。使用三脚架或支架；同一批实验中不要变焦、转动或碰到相机。只要相机不动，标定一次就能用于所有视频。
  2. 旷场类和迷宫类实验尽量从正上方俯拍，画面包含整个场地并留出一点余量（高架十字迷宫四周要留空间，让小鼠探头时鼻尖仍在画面内）。
  3. 光照均匀柔和，地面上不要有硬阴影或反光。灰度或红外视频效果很好；姿态类任务默认会先转灰度再识别。
  4. 对比度：深色小鼠配浅色底面（或反之）追踪效果最好。
  5. 帧率：大多数范式 25–30 fps 即可。步态分析请从透明步道下方以≥ 60 fps 拍摄。快速的头部动作（VTE、探头）建议逐帧识别。
  6. 每段视频一只动物，多格 TST 流程除外（多只小鼠并排悬挂）。“双鼠社交互动”在 iPhone/iPad 上可追踪两只鼠；Mac 版目前该范式只追踪一只。

各范式的拍摄视角

  • 悬尾实验（RodentLimb，单鼠）：从正面或背面拍摄悬挂的小鼠，两只后爪都要可见；悬挂时开始录像；标准测试时长 6 分钟。
  • 多格 TST：相机固定并正对装置，所有格子都在画面内；锁定曝光，避免亮度闪烁；易爬尾的品系（如 C57BL/6）请使用防爬装置。
  • 圆筒实验：透过透明底面仰拍效果最好；侧拍也可以，需标定地面线。每只鼠 5–10 分钟。
  • 步态：从下方（腹侧）拍摄直的步道；在画面中放一次标尺，用于厘米标定。
  • 旋转行为：如透过透明底面拍摄，请在参数中打开“从下方拍摄（画面左右镜像）”。

文件格式与命名

  • 使用普通的 MP4 或 MOV（H.264 或 HEVC 编码）。如果某个文件打不开，可用免费的 HandBrake 转成 H.264 MP4。
  • 文件名建议为 小鼠编号_YYYY-MM-DD，例如 M01_2026-10-17.mp4。Mac 版会从文件名读取日期（支持 2026-10-17、2026_10_17、2026.10.17、20261017），去掉日期后剩下的部分作为小鼠编号，导入表格几乎能自动填好。文件名中没有日期时，会改用文件创建日期并提示你核对。
  • 原始视频不要再挪动。Mac 版直接读取原位置的视频，绝不修改它们；之后若移动或重命名文件，App 就打不开了。请在导入之前把视频放到最终的文件夹（并做好备份）。多格 TST 录像和 iPhone/iPad 导入的视频则会复制一份到 App 内。
  • 只使用你有权使用的视频，未发表的录像请遵守所在机构的数据管理规定。

3. 理解这五点，用起来更顺手

1. 一段视频 = 一只小鼠的一次实验。
每段视频只属于一只小鼠，并有实验日期和实验次数（1、2、3……即该小鼠在此任务中的第几次）。在 Mac 版中，这三项是分析前的必填项。
2. 层级本身就是数据。
项目 → 任务 → 分组 → 小鼠 → 实验。“任务”是一个行为学测试（如“旷场—第 3 批”）。分组（WT、KO、对照……）可选，并且属于小鼠：修改某只小鼠的分组或性别，会同时应用到它在该任务中的所有实验。
3. 任务决定方法。
你不需要选模型。选定任务，就决定了标定方式、分析方法和模型（6 关键点姿态、7 关键点四肢姿态、经典质心追踪或多格轮廓评分）。
4. 追踪一次，评分多次。
追踪（最耗时的部分）只做一次。区域、阈值和分析时间段在追踪之后才应用，修改后结果无需重新追踪即可更新。原始视频只读不改。
5. n = 小鼠数。
汇总和统计时，同一阶段内一只小鼠纳入的多次实验先取平均，因此 n 是小鼠数——不是实验数，更不是帧数。不同阶段（如训练与测试）不会合并，除非你明确选择。

4. Mac 快速上手（10 步）

  1. 打开 RodentFlow。切换中文 / English：工具栏的地球图标“语言”菜单，或 RodentFlow › 设置…（⌘,）。
  2. 新建任务：点新建任务…（⇧⌘N），在“要测量哪种行为？”中选择测试（可搜索）。项目会自动创建。
  3. 添加视频：点 + 添加视频…（⌘O），或直接把文件拖到侧栏 / 中间列表。
  4. 核对导入表格：小鼠编号、日期、实验次数必填；分组、性别可选。用“新小鼠的分组 → 应用”可一次填满一列。点导入。
  5. 在中间列表打开一次实验，按顶部四步进行：① 实验信息 → ② 校准 → ③ 分析 → ④ 复核与导出（⌘[ / ⌘] 切换上一步 / 下一步）。
  6. 校准：把彩色手柄拖到场地上（拖动时会出现放大镜），输入场地实际尺寸（cm），设置分析时间段，然后点仅保存到本视频（⌘S）。若相机没动过，可选用于该任务的所有视频…
  7. 分析：点分析该视频（⌘R）。其他视频会排入队列；运行期间可继续标定或复核其他动物，也可随时暂停 / 继续分析。
  8. 复核追踪：在“复核与导出 → 逐帧复核与导出”中播放第 0–99 帧（⌥P），标记错误帧（⌥F），记录结论“追踪无误”或“追踪有问题”。然后点下一次待复核的实验 →。
  9. 查看数值：“结果”页显示该范式的指标和图表。点侧栏中的任务，可看到全部实验和组间比较。
  10. 导出：在任务页点导出任务数据…，会生成一个包含英文 CSV 和 README_methods.txt 的文件夹，可直接用于 R、Python、Prism 或 Excel。

小贴士：同一批的第一只小鼠请认真标定和复核。同一任务的新视频会沿用上一个视频的标定（会显示“标定沿用自 ……，请检查”），之后的动物通常只需快速确认。

5. Mac：完整流程

5.1 窗口布局

一个窗口，三栏：

  • 侧栏（左）分三部分：
    • 任务——每个任务，展开后是它的分组；数字角标为实验数量。
    • 智能列表——跨所有任务汇总需要处理的实验：全部实验、待分析、待复核、缺信息（缺小鼠编号、日期或实验次数）、已排除，以及仅在存在时显示的未分配任务（早期版本导入的视频）。
    • 工具——高级工具（见 5.9）。
  • 中间列表——所选任务 / 分组的小鼠及其各次实验（有分组时按组分段），或智能列表中的实验。顶部可搜索小鼠、分组或日期。点空白处回到任务 / 分组总览。
  • 右侧页面——任务或分组总览、小鼠页，或某次实验的四个步骤。

⌘1 任务 · ⌘2 全部实验 · ⌘3 工具。侧栏可用工具栏按钮隐藏。用 ⌘+ / ⌘− 放大或缩小字体（或在设置 › 字体大小中选择 紧凑 / 标准 / 大 / 特大）。

5.2 新建与管理任务

新建任务…会打开“要测量哪种行为？”。任务按模块分组，每行都注明测量方法：

模块方法任务
RodentPoseCore ML 姿态模型，6 个关键点（鼻尖、双耳、颈部、身体中心、尾根），逐帧识别从社交到运动共 16 个范式——见速查表
RodentLimbCore ML 四肢模型，7 个关键点（四只爪、尾根、鼻尖、嘴）圆筒实验、悬尾实验、步态分析
RodentFlow经典质心追踪，10 Hz（背景差分，不使用神经网络）10 个视频范式——见速查表
悬尾实验 · 多格同步评分格子检测、关键帧、逐格轮廓 / 像素运动一段录像中的多只小鼠——见第 6 节

同一个测试出现在两个模块里？旷场、高架十字迷宫、明暗箱、新物体识别、Y 迷宫、T 迷宫、Barnes 迷宫和恐惧条件化在 RodentPose 和 RodentFlow 中都有。需要头朝向、基于鼻尖的物体 / 社交探索、探头或伸展评估姿势时选 RodentPose；需要经典的基于位置的指标、Morris 水迷宫或条件性位置偏好，或者姿态模型难以看清动物时选 RodentFlow。同一项研究请固定使用一个模块——两者的指标不能互换。

任务备注：右键任务 → 添加／编辑备注…（如“第 3 批，10 mg/kg”）。备注显示在任务名下方，并会导出。

同名任务：名称、实验类型和备注都相同（包括都没有备注）的任务会自动合并，所以重复新建“旷场”不会把数据拆散。需要两个独立的同名任务？右键 → 按不同备注新建同名任务…。若合并会造成实验次数冲突或分组 / 性别矛盾，程序不会自动合并；合并前也会先备份工作区。

删除任务：右键 → 删除任务…。会把该任务及其实验记录从项目中移除（如有分析在运行，请先暂停）。视频文件和已保存的追踪结果文件夹会保留，但此操作无法在 App 内撤销。

5.3 添加视频

选中一个任务（或其中的分组 / 小鼠——会自动预填该分组 / 小鼠），点 + 添加视频…（⌘O），或把视频拖到侧栏或中间列表。导入表格每行一个视频：

列填写内容
小鼠编号 *在任务内唯一，如 M01。由文件名预填。
分组可选（WT、KO、对照……）。该任务中已有实验的小鼠沿用原分组。
性别可选，属于小鼠（RodentPose、RodentFlow 和 TST 任务显示）。
日期 *实验日期。由文件名预填，否则取文件创建日期（请核对！）。“全部使用第一行的日期”可一键统一。
实验次数 *该小鼠在此任务中的第几次实验。自动填入下一个可用编号。
阶段用于有固定阶段的任务（如新物体识别 训练 / 测试）。

有问题的行会标红（缺编号、实验次数已被占用、列表中同一小鼠的实验次数重复），修正前“导入”按钮不可用。拒绝重复是有意为之：重复记录会悄悄污染统计结果。

5.4 第 ① 步 实验信息

  • 小鼠、分组、性别——分组和性别应用于该小鼠在此任务中的所有实验；输入一个已有的小鼠编号，会把这次实验归入那只小鼠。
  • 实验日期、实验次数——必填。
  • 阶段 / 天 / 当天试次——范式需要时显示（如 Barnes 迷宫的学习天数和试次）。汇总时不同阶段不会合并。
  • 备注——剂量、处理、异常情况等（RodentPose 和 RodentLimb 任务显示；RodentFlow 可用任务备注记录批次信息）。
  • 排除出组间汇总——需填写原因（会导出）。被排除的实验保留自己的结果，但不进入小鼠均值、组统计和组间比较。排除标准请在看结果之前确定。

缺少小鼠编号、日期或实验次数的实验会显示橙色标记并出现在“缺信息”中，补全前不能分析。

5.5 第 ② 步 校准

校准告诉 App：场地在哪里、实际多大（厘米）、物体或区域在哪，以及分析视频的哪一段。

  1. 用时间滑块选一帧标定画面（场地边缘清晰、没有被手挡住）。
  2. 若范式提供多种场地，选择场地类型（矩形、圆形、十字 / Y / T 迷宫，或仅导出姿态时的“不标定（像素）”）。
  3. 拖动手柄。拖动时会显示 3 倍放大镜。需要精确时，点选手柄后用方向键微调（按住 ⇧ 移动更多）。
  4. 输入实际尺寸（内部宽 / 高、直径、臂长 / 臂宽）。面板会显示比例（约 x 像素 / cm），可顺手核对是否合理。
  5. 设置范式参数（区域大小、哪个是新物体、CS 开始时间……）和分析时间段（起点和时长；0 = 到结尾）。
  6. 点仅保存到本视频（⌘S）；之后的修改自动保存。用于该任务的所有视频…会把它复制到所有视频——仅在相机未移动时使用。

5.6 第 ③ 步 分析

  • 点分析该视频（⌘R）。若已有视频在运行，按钮会变成“加入队列”。视频按顺序逐个分析。
  • 页面显示进度、视频时间、预计剩余时间以及实时追踪预览（约每秒更新一次）。
  • 暂停会保留已完成的部分；继续分析从停下处继续——即使退出过 App 也可以。长视频会分段写入磁盘，内存占用可控。
  • 同一页面的“该任务的全部动物”卡片 → 分析其余视频（n 个）会把所有准备就绪的视频加入队列；“全部暂停”可停止队列。缺信息或（RodentFlow）未标定的视频会被列出并跳过。
  • 重新分析…会保留之前的结果，复核将使用新结果（之后请重新复核追踪）。

5.7 第 ④ 步 复核与导出

“结果”页

显示该次实验按原版算法得到的指标与图表，突出主要指标，并标明当前的分析时间段和阶段。时间段、区域或参数请在“校准”中修改——结果会重新计算，无需重新追踪。导出结果与图表…会把这次实验的指标、方法说明以及（可选）PNG 图表写入一个新文件夹。

逐帧复核与导出：追踪复核

不需要看完整段视频。一次简短而有条理的检查就能发现大多数问题：

  1. 选择复核范围（默认第 0–99 帧）或快捷选项：开头、中间、结尾、随机。
  2. 按播放（⌥P），速度可选“逐帧播放”、0.25×、0.5×、1×、2×；或用 ⌥← / ⌥→ 逐帧查看。橙色线为之前 2 秒的轨迹。
  3. 遇到关键点明显错误的帧，按 ⌥F（此处追踪错误）。
  4. 记录结论（未复核 / 追踪无误 / 追踪有问题）和备注，它们随该次实验保存并导出。
  5. 点下一次待复核的实验 →（或右上角的“下一次实验 →”）。

结论为“追踪有问题”的实验不会被自动排除——由你按预先设定的标准决定。若解码画面与追踪时间戳对不上，App 会隐藏标点，而不是画在错误的位置。

追踪事件、图表与原始文件（RodentPose / RodentLimb）

  • 追踪质控事件把连续的“识别失败”“未检测到小鼠”“置信度低”帧合并显示。这些是质量标记，不是行为；追踪质量好的视频可以没有任何事件。点击事件可跳转；可标为“接受”或“标记问题”。
  • 选择作图帧范围（含首尾，从 0 开始），勾选要导出的内容：原始关键点 CSV、质控筛选后的 CSV、逐帧 / 分段质控 CSV、溯源 JSON、轨迹图和置信度图 PNG、标注截图，以及（RodentLimb）事件时间线。点导出所选文件和图表…（⌘E）。图表由已保存的追踪数据生成，这里不会重新运行模型。
  • 标注 MP4 为可选项：App 会先测速估时，确认后再导出，不会重复运行模型。
  • RodentFlow 实验在同一页面导出 10 Hz 质心采样点（CSV）和追踪复核记录（JSON）。

5.8 任务页、分组页、小鼠页

  • 任务页：全部实验的表格（小鼠、分组、日期、实验次数、阶段、分析状态、主要指标、追踪复核、是否纳入）。双击打开；多选后右键可用同一原因批量排除 / 重新纳入。标签页：全部实验、组间比较、导出。
  • 分组页：该组的小鼠、各阶段描述统计（每只小鼠先取均值，n = 小鼠数）、组级导出，以及重命名分组（应用于此任务中该组的所有小鼠）。
  • 小鼠页：该小鼠的各次实验、某一指标随实验次数的变化（已排除的实验为灰色），以及重命名 / 修改分组 / 性别。改成已有编号时，只有在实验次数不冲突时才会合并。

打开这些页面时，缺少或过期的实验结果会在后台按顺序计算（进度显示在页面顶部，可“停止”）。结果随每次追踪保存；它所依赖的任何内容改变时会自动重算。

5.9 智能列表与工具

全部实验（⌘2）是项目中所有实验的一张总表，含标定、分析和追踪复核状态——适合最后做一次完整性检查。右键可“在所属任务中打开”或“从项目中移除”（文件本身不会被删除）。

6. 多格悬尾实验（TST）

该流程用于对同一段录像中并排悬挂的多只小鼠评分：自动找到格子，找到所有小鼠都已挂好的时刻（关键帧），逐格测量运动，然后把每个格子保存为一只小鼠的一次普通实验——因此分组、组间比较和导出与其他任务完全一样。（若每段视频只有一只小鼠，并需要爪部关键点、抱握和爬尾判定，请改用 RodentLimb 的“悬尾实验”任务。）

操作步骤

  1. 新建任务“悬尾实验 · 多格同步评分”，点添加 TST 录像…（⌘O）或把视频拖到侧栏。录像需逐段分析。分析窗口顶部有步骤条——视频 › 格子 › 关键帧 › 结果与小鼠；左边看画面，右边调设置，底部固定“上一步 / 取消（Esc）/ 下一步（Return）”。
  2. 格子：程序会自动检测格子（检测不到时先平均分成 6 格）。设置“格子数”，把白色手柄拖到格子之间的隔板上，点击格子可选中或跳过。检测到小鼠的格子已预先勾选。然后点寻找关键帧 →（视频已剪辑为所有小鼠挂好之后才开始时，可用“手动设定起点…”）。
  3. 关键帧：所有选中格子都已有小鼠并持续设定时长的第一个时刻。找到后即可点“采用此关键帧 →”，但让扫描完整跑完，各格的运动框才能覆盖小鼠的全部活动范围，并能看出小鼠何时被取下。可用 ±0.25 秒 / ±1 秒按钮或点击时间轴微调。拖动黄色手柄，使分析带覆盖每只小鼠并在上方留一点空间。然后点开始分析 →。
  4. 结果与小鼠：一格一行，同时显示不动时间和小鼠信息。实验日期整段录像只填一次；逐格填写小鼠编号、分组、性别、实验次数；空格或不可用的格子取消勾选（不会生成实验记录）。只有真正的冲突才会标红。点保存 N 次实验。
  5. 小鼠会出现在侧栏，并自动打开第一只的“复核与导出”：打开原始录像检查该格，选择“评分无误”或“存在问题”（选中即保存），必要时填写原因并排除。

评分原理

  • 每只小鼠从自己挂上的时刻开始计时。标准测试时长 6 分钟。主要指标（★）是第 2–6 分钟的不动时间；同时报告第 0–2、0–6 分钟和全程，以及首次不动潜伏期、不动次数 / 平均 / 最长片段、每分钟不动时间和运动强度（活动时的平均运动量，即挣扎的剧烈程度）。
  • 默认指标是每只小鼠固定运动框内的像素变化，比较前先对齐画面以抵消被动摆动（摆动不计为运动）。另有两种基于轮廓的指标可供对照。
  • 默认从关键帧分析到视频结束；需要固定时长时打开“到此为止（限定时长）”。没有小鼠的帧（已取下、爬尾、出画）计为“无小鼠”，不计为不动；不动百分比的分母只包含有小鼠的帧。
  • “无小鼠”帧超过 10% 的格子会提示复核。若某只鼠挂上后没录满 6 分钟，也会给出提示。

请针对自己的装置校准阈值。TST 自动评分尚未经过盲法人工评分验证，默认阈值（鼠体的 2%）只是起始值。先人工评分 2–3 段不动程度不同的视频（例如使用 BORIS），然后在“结果与小鼠”中点用人工评分校准阈值…：填入人工评分的秒数（第 2–6 分钟），点“寻找最佳阈值”并应用。整个研究使用同一阈值。

之后修改设置

打开任意一次 TST 实验，点调整参数并重新分析…（右键菜单中也有）。录像会以原来的格子、起点和参数重新打开。阈值、最短不动片段和时间窗可立即修改；改格子、分析带或起点则需重新分析。更新实验会原地更新已有实验（实验 ID 不变；因数值改变，复核结论会清空，备注保留），为新勾选的格子新建实验，并删除不再保存的格子对应的实验（删除前会提示数量）。

如何解读 TST 结果

不动时间更准确的说法是被动应对策略，不宜直接称为“抑郁样”行为。镇静或兴奋、运动能力、体重、性别、品系和尾部不适都会影响结果，建议配合运动能力对照（如同一批小鼠的旷场总距离）一起解读。参见 Can 等 2012 和 Commons 等 2017。

7. 组间比较与统计（Mac）

打开任务，选择组间比较。依次选择设计、指标、阶段、纳入哪些实验（全部实验（按小鼠取平均）或仅第 n 次）、统计（参数检验 / 非参数检验）和比较方式（两两比较 / 与第一组比较）。

设计每只小鼠的值检验（两组 · ≥ 3 组）
组间比较其纳入实验的均值Welch t（附 95% CI）或 Mann–Whitney U · 单因素方差分析 + Tukey–Kramer，或各组与第一组比较 + Holm；Kruskal–Wallis + Dunn（Holm）
按实验次数每个实验次数一个值两因素混合方差分析（组 × 实验次数，Greenhouse–Geisser 校正）+ 各次组间检验（Holm 校正）
按天同一天的试次先平均（学习曲线）同上
时间进程一次实验内的序列（时间段、CS 呈现、TST 每分钟）同上
配对指标同一小鼠的两个指标（新物体 vs 熟悉物体、开放臂 vs 闭合臂）组内：配对 t / Wilcoxon；组间：交互作用或差值检验
阶段间变化每只小鼠 阶段 B − 阶段 A（如 测试 − 前测）同“组间比较”
  • 对照组排第一：名称像对照的组（WT、Control、Vehicle、Saline、Sham）默认排在最前；可在列表中调整顺序、颜色和是否纳入，设置按任务保存。
  • 参考值：对有天然“无偏好值”的指标（DI = 0、识别指数 = 50%、目标象限 = 25%），可勾选各组与参考值比较。
  • 选项：显示每只小鼠；包含已排除的实验（仅用于敏感性查看）。
  • 导出该比较…会生成图（PNG）、方法与结果摘要（TXT）、完整结果（JSON）和每只小鼠进入检验的数值（CSV）。

这些是用于初步查看数据的统计：没有对多个指标、多种设计或多次查看数据做校正。每组少于 2 只时不给检验结果（并说明原因）。报告前请用预先设定的分析确认——导出的 animals.csv 和 comparison_animal_values.csv 可直接用于 R、Python 或 GraphPad Prism。

9. iPhone 与 iPad

RodentFlow Mobile 在设备上运行同一个 6 关键点 RodentPose 模型和 16 个 RodentPose 范式。App 有三个标签页：首页、范式库、数据；设置在首页右上角的齿轮图标里。

第一次分析

  1. 首页 → 新建分析。选择范式（或点“常用范式”中的一个；“范式库”介绍了每个范式用到的关键点、输出指标、拍摄与标定要求和参考文献）。
  2. 导入视频：“从相册选择视频”或“从‘文件’选择视频”。视频会复制一份到本次分析的文件夹，便于之后回看。模型还在加载时，也可以先导入视频并完成标定。
  3. 信息：填写编号（用于文件名和汇总表，建议在识别前填写）、组别（用过的组别会显示在输入框下方，轻点即可填入）、性别、阶段 / 条件（轻点 + 添加自己的标签，如“Day 1”“Baseline”；长按可移除）、天、试次和备注。
  4. 识别设置（也在“信息”页）：抽帧（每帧，或长视频每 2 / 3 / 5 帧识别一次——速度和僵直按实际时间计算，但 VTE、探头等快速动作请逐帧）、先转灰度再识别（建议开启）、双鼠模式（双鼠社交互动）以及识别范围。之后修改这些需要重新识别。
  5. 标定：拖动手柄（标签与 Mac 版相同，见 5.5）。拖动时对侧上角会出现放大镜。识别完成后打开叠加已识别轨迹，可检查标定范围是否与动物的实际活动范围吻合。VoiceOver 用户可在操作菜单中逐步微调手柄。
  6. 识别：点“开始识别”。识别期间请保持 App 在前台（屏幕不会自动锁定）。切到后台会自动暂停并保存进度，回来后点“继续识别”即可。
  7. 结果：主要指标（有意义时附刻度，如 0 = 无偏好）、全部指标、图表、识别质量，以及可一键复制的方法说明（可用于论文 Methods）。每张图都有 ••• 菜单：复制图像、分享图像…、复制数据（CSV，英文）。
  8. 下一只（同范式）会用同一范式开始下一次分析；相机没动过时可沿用标定。

11. 让结果经得起检验

RodentFlow 是科研辅助工具，不是诊断工具。它的指标是基于关键点几何关系或运动信号的算法估计，质量取决于你的录像、标定和阈值；桌面版分析器是原版算法的移植，与原版 App 的数值一致性仍在验证中。

  1. 在自己的装置上验证。每个范式人工评分几段视频（对分组设盲），与 RodentFlow 结果对比，在正式实验之前把阈值调好一次。BORIS 是免费的人工行为评分工具。
  2. 固定参数。同一研究中所有动物使用相同的标定方法、分析时间段和阈值。这些参数都会写入每份导出。
  3. 每次实验都复核追踪（检查 100 帧不到一分钟），并提前确定排除标准（如掉落迷宫、检出率 < 80%）。App 会列出质控警告，但从不自动排除。
  4. 尊重实验单位。n = 小鼠数，而不是实验数或帧数（Lazic 等 2018）。不要合并不同阶段。
  5. App 内统计仅作初步参考，请对导出的 animals.csv 运行你预先注册的分析。
  6. 如实报告：App 版本、范式、模型或追踪方法、标定、分析时间段、阈值、排除情况——README_methods.txt 和移动版的“方法说明”可作为初稿。请参照 ARRIVE 2.0 指南。
  7. 谨慎解读。“鼻尖靠近物体”是探索的近似指标；“运动量低”是僵直或不动的近似指标。焦虑、记忆、应对类指标都应配合运动能力对照一起解读。

14. 常见问题排查

导入

以前能用的实验提示“无法打开视频”

文件被移动、重命名、删除，或位于未连接的外置 / 网络硬盘上。请连接硬盘或把文件放回原处。否则，把这次实验从项目中移除后重新添加视频（并重新检查标定）。

视频无法导入或没有画面

可能是 macOS / iOS 不支持该编码。请用 HandBrake 转成 H.264 MP4（如“Fast 1080p30”预设）后重试。若普通的 H.264 MP4 仍然失败，请反馈给我们。

“文件名和文件中没有日期” / 日期不对

导入前把日期写进文件名（M01_2026-10-17.mp4），或在导入表格中手动填写。整批视频同一天录制时，用“全部使用第一行的日期”最方便。

“M01 在此任务中已有第 1 次实验”

同一任务中，每只小鼠的实验次数必须唯一。请改用下一个编号（表格会给出建议），或检查是否重复导入了同一段视频。

某次实验在“缺信息”中，无法分析

打开它，在“实验信息”中补全小鼠编号、实验日期和实验次数。早期版本导入的实验可能需要补一次。

分析

“此版本未安装分析模型”

你使用的版本编译时没有包含 Core ML 模型。App Store 版本已内置模型。若是自行编译，请运行 git lfs pull 让模型权重成为真实文件，然后重新编译（见从源码编译）。“工具 › 模型”可查看安装情况。

“请先标定场地”（RodentFlow）

RodentFlow 追踪器需要先知道场地位置。进入“校准”，放好手柄并保存后再分析。

分析很慢

姿态追踪逐帧进行；视频长、分辨率高时需要较长时间，Intel Mac 尤甚。让队列在后台运行（你可以继续做别的），关闭其他占用资源的 App，并接通电源。在 iPhone/iPad 上，若不需要快速头部动作，长视频可每 2–3 帧识别一次。

分析中断，或 Mac 进入了睡眠

点“继续分析”——已完成的分段会保留。“分析失败”会显示原因；“重试”会从头开始。若某段视频反复失败，可尝试重新编码。

检出率低 / 关键点乱跳

检查光照、对比度、反光以及动物是否出画。用“逐帧复核”找到问题帧。提高关键点置信度阈值可隐藏不确定的点；平滑和缺口插值（校准 › 分析时间段与预处理）能减少抖动，且无需重新追踪。

结果明显不合理（如中央区时间 0%、距离极大）

通常是标定问题：手柄放在外壁而非内壁、场地尺寸填错，或分析时间段不对。检查像素 / cm 比例和手柄位置，并把轨迹与区域对照查看。

同一段视频，RodentPose 和 RodentFlow 结果不同

这是正常的。RodentPose 使用关键点（如用鼻尖判断物体探索）；RodentFlow 使用 10 Hz 的身体质心，区域定义也不同。同一研究请固定使用一个模块。

逐帧复核时关键点被隐藏

解码画面与追踪时间戳（或画面方向）不一致，为避免误导性复核而隐藏了标点。换到相邻帧即可；原始数据不受影响。

多格 TST

没能自动找到格子

画面会先平均分成 6 格。请设置正确的格子数并把白色手柄拖到隔板上，或点“重新检测”。

“没有找到所有选中格子同时有小鼠……的时刻”

检查是否只选中了有小鼠的格子，在“检测设置…”中降低“最低置信度”，或使用“手动设定起点…”。浅色小鼠请把“小鼠颜色”改为“浅色小鼠 / 深色背景”。

轮廓不贴合小鼠

停止后调整分析带使其覆盖小鼠，或在“检测设置…”中修改小鼠颜色。手、袖子和阴影会干扰经典检测器；可在检测设置中导入针对你装置微调过的 YOLO 模型。

“结果”步骤变灰

自上次分析后起点、分析带、格子或时间窗已改变。点“重新分析”以更新结果。

“无小鼠”帧超过 10%

小鼠爬尾、被提前取下或离开了画面。请在原始录像中复核该格；如不符合你的标准，填写原因后排除。

iPhone 与 iPad

识别自己暂停了

App 被切到后台或设备锁屏了。进度已保存；打开该分析点“继续识别”。识别期间请保持 App 在前台。

旧的分析无法回看或重新识别

为节省空间删除了视频副本。结果和姿态数据仍在；如需回看，请用原始视频新建一次分析。

姿态模型一直在加载

加载期间可以先导入视频和标定。若一直无法就绪，打开设置点“重新加载”；重启 App 也有帮助。

导出

Excel 中中文显示为乱码

通过“数据 › 从文本/CSV”以 UTF-8 编码导入，或用 Numbers 打开。列名为英文，不受影响。

任务导出中部分实验没有数值

它们的结果还在计算中。等任务页顶部的进度完成后再导出。未分析或（RodentFlow）未标定的实验没有数值。
