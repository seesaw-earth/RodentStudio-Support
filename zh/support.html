支持与帮助

RodentStudio macOS 版的问题反馈、常见故障排查和使用支持。

需要帮助？ 可以使用公开 GitHub Issues 提交报错、功能问题或文档建议。请勿公开上传未发表科研视频、个人信息或保密资料。
提交问题 ↗创建 GitHub Issue（需要 GitHub 账号）查看已知问题 ↗搜索现有问题与处理进度阅读使用指南 →导入、标定、分析和导出查看常见问题 →模型、视频和数据管理

提交问题时请提供

  1. RodentStudio 版本与构建号（例如 0.6.3 / Build 6）。
  2. macOS 系统版本，以及 Apple Silicon 或 Intel 芯片。
  3. 使用的分析模块（RodentPose、RodentLimb 或 RodentFlow）。
  4. 复现步骤、错误提示原文。
  5. 可公开的截图或模拟视频；不要公开上传真实受限研究数据。

涉及隐私或保密数据怎么办？

GitHub Issues 是公开的。如果问题包含隐私、机构限制或未发表数据，请仅创建一个请求私下联系的 Issue，不要在公开页面粘贴任何敏感细节。开发者可以再协调非公开沟通方式。

支持范围

包括安装、导入视频、Core ML 模型加载、分析流程、结果导出和软件缺陷。软件支持不构成临床、兽医诊断或实验方案指导。
