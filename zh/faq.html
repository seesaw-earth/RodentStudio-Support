常见问题

文件、隐私、模型和科研使用中的常见问题。

RodentStudio 会上传我的科研视频吗？

已审阅源代码版本在本机处理数据，没有开发者运营的视频上传功能。请阅读隐私政策。

使用 Mac App 是否需要 Python、GitHub 或联网？

计划发布的 Mac App Store 包会将必要 Core ML 模型内置，本机分析不需要 Python 或 GitHub 账号。最终提交版仍需进行实际安装测试。

可以导入哪些视频格式？

通常为 MP4 与 MOV。实际兼容性取决于内部编码格式；遇到问题可以尝试常见 H.264 MP4 并提交错误信息。

我的数据保存在哪里？

工作区和运行记录保存在本地 Application Support 应用目录；导出文件在你选择的位置。建议独立备份原始视频。

删除任务会自动删除原始视频吗？

不一定。删除任务记录后，源视频或部分追踪文件可能仍保留在磁盘，请自行核对。

可以做组间统计吗？

部分流程提供小鼠级与分组级统计。应核实实验单位、重复实验、排除标准和多重比较等问题。

Mac 版已经支持 JABS 12 点模型了吗？

JABS 模型可以存在于独立模型仓库，但已经审阅的 0.6.3 工程里，Mac 原生 Core ML 姿态跟踪使用 MousePose6 和 CylinderMousePoseV2，不能据此宣称第三个模型已经接入。

怎么提交错误？

通过支持页面附上版本、系统、芯片、模块及复现步骤，不要公开上传保密科研数据。

它能做临床或兽医诊断吗？

不能。这是科研辅助分析工具，不是诊断或治疗设备。
