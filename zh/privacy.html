隐私政策

RodentStudio 对视频、实验信息和分析结果的数据处理说明。

生效日期：2026 年 10 月 18 日 · 适用于 RodentStudio macOS 0.6.3 候选版本。

摘要：根据已审阅的源代码，当前版本不含账号登录、内置广告、开发者运营的分析 SDK 或视频上传服务器。导入视频与分析结果主要在本机处理与保存。正式发布前仍需核对最终签名版本。

1. 开发者和联系渠道

RodentStudio 由 Ziqing Shi 开发。如有软件支持或隐私疑问，请访问支持页面。公开 Issues 不是安全的敏感信息传输渠道；涉及隐私时，请仅提出希望私下联系，不要公开粘贴个人信息。

2. 软件处理的数据

你可以自行选择研究视频，填写项目名称、实验条件、小鼠编号、分组、备注、标定点、逐帧复核注释等信息。软件根据所选分析流程在本机计算姿态、运动轨迹、图表及导出文件。

3. 数据收集与传输

根据已审阅版本，软件不向开发者运营的服务器上传这些科研数据，无需注册账户，不包含广告 SDK，也不包含开发者运营的数据分析收集功能。如果你主动通过其他服务分享导出文件，则不属于软件本身的数据传输。

4. 本机存储与权限

工作区及运行记录存放在 macOS 的 Application Support 应用数据区域。原始视频和导出文件也可能保存到你选择的位置。软件读取和写入文件需要 macOS 授予的相应权限。RodentPose 与 RodentLimb 的支持流程使用本机 Core ML 推理；RodentFlow 的部分流程采用传统质心跟踪。

5. 保留与删除

本机数据会保留到你或操作系统删除为止。导出文件可以通过 Finder 管理。在 App 内删除任务，不一定会自动删除源视频和全部分析文件。删除项目或卸载 App 前，请备份科研数据并核实文件位置。开发者无法远程删除你本地保存的文件。

6. 第三方与网站托管

你自行使用第三方服务分享文件时，适用对应服务的隐私条款。本支持网站托管于 GitHub Pages，GitHub 可能根据其隐私声明处理网站连接和使用数据。本网站没有添加自定义访问统计脚本，也不设置资料提交表单。

7. 安全和更新

建议保持 macOS 更新，妥善保管保密视频和数据，遵守机构的数据管理要求。若未来版本更改数据收集或传输方式，将及时更新本页面。

该声明基于源代码与隐私清单审阅。发布者仍须审查最终 App Store 二进制包与所有第三方组件。
