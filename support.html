Support & help

Questions, bug reports and practical help for RodentFlow on macOS.

Need help? Use the public support tracker for bug reports, feature questions, or documentation corrections. Do not post sensitive research data or personally identifying information in public issues.
Open a support request ↗Submit a GitHub issue (GitHub account required)Browse known issues ↗Check existing reports and responsesRead the user guide →Import, calibrate, analyse and exportTroubleshooting & FAQ →Models, video files and data storage

Information to include

  1. RodentFlow version and build (for example, 0.6.3, build 6).
  2. macOS version and whether your Mac uses Apple silicon or Intel.
  3. Which workflow you used (RodentPose, RodentLimb or RodentFlow).
  4. Steps to reproduce the problem and the exact error message.
  5. If relevant, a non-sensitive screenshot or a synthetic test clip. Never upload unpublished research recordings without permission.

Privacy or sensitive requests

GitHub issues are public. If your question involves personal, confidential, or unpublished information, open an issue containing only a request for a private contact channel; do not include the sensitive details. The developer can coordinate an appropriate private follow-up.

What support covers

Installation and app behavior, access to user-selected video files, Core ML model loading, import/export questions, and reproducible defects. RodentFlow does not provide clinical, veterinary, or experimental protocol advice.
